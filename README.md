# התקציב שלי - גרסה 1

אפליקציית תקציב בעברית, ללא צורך בשרת, לשימוש במחשב או בטלפון.

## הפעלה
פתחו את `index.html` בדפדפן או העלו את קובצי התיקייה לשורש מאגר GitHub והפעילו GitHub Pages.

## יכולות
- הכנסה חודשית נטו והוצאות קבועות נפרדות.
- תקרות הוצאות משתנות לפי קטגוריה.
- הוספה, עריכה ומחיקה של הוצאות עם תאריך ותיאור.
- מעבר בין חודשים והעתקת הגדרות מהחודש הקודם בעת יצירת חודש חדש.
- תצוגת היתרה אחרי הוצאות בפועל לעומת יתרת התקציב המשתנה.
- גיבוי וייבוא JSON וייצוא הוצאות CSV.

## חשוב
המידע נשמר רק באחסון המקומי של הדפדפן (localStorage), ללא סנכרון בין מכשירים וללא הצפנה. מומלץ לייצא גיבוי בקביעות. הוצאות קבועות נזקפות במלואן לחודש לצורך תכנון, גם אם טרם שולמו בפועל. האפליקציה אינה מחוברת לבנק.
